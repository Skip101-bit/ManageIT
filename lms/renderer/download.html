LMS Scope of Work

Download the Windows desktop app for Legend & Scope of Work proposals.

Download for Windows
  1. Click the button above to download the installer.
  2. Open the downloaded file and follow the setup steps.
  3. Launch LMS Scope of Work from the Start menu.
If Windows blocks the installer:
  • Blue “Windows protected your PC” screen: click More info, then Run anyway.
  • “Smart App Control blocked an app”: open Windows Security → App & browser control → Smart App Control and turn it Off, then run the installer again. Windows will not let you turn Smart App Control back on later without resetting the PC.
  • Or right-click the downloaded .exe → Properties → tick Unblock → OK, then open it.
This is an LMS in-house app. Windows flags it because the installer is not code-signed yet.

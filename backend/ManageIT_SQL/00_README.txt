================================================================
 MANAGEIT - SQL SERVER (SSMS) DATABASE DEPLOYMENT PACKAGE
================================================================

HOW TO DEPLOY (in SSMS):

1. Open SSMS, connect to your SQL Server instance.
2. Open file 01_CREATE_DATABASE.sql and execute it.
   (Creates the ManageIT database)
3. Make sure your query window is using the "ManageIT" database
   (select it from the database dropdown, top-left of toolbar).
4. Open and execute, IN ORDER:
     02_CREATE_TABLES.sql
     03_CREATE_AUDIT_TABLES.sql
     04_CREATE_TRIGGERS.sql
     06_EXTRA_TABLES.sql
     07_CREATE_STORED_PROCEDURES.sql
     08_STOCK_STORED_PROCEDURES.sql
     05_SEED_DATA.sql   (optional - demo data)

OR simply open and run 00_MASTER_DEPLOY.sql, which runs everything
in the correct order in one go.

================================================================
WHAT'S INSIDE
================================================================

TABLES
  - Users                (login, roles: Admin / User)
  - Departments
  - Jobs                  (job management)
  - StorageLocations      (racks, shelves, etc.)
  - StockItems            (general / service / job stock)
  - StockTransactions     (book in / book out / transfer history)
  - ActivityLog           (user activity feed)
  - Settings               (key/value app settings)

AUDIT TABLES (one per main table)
  - Users_AuditLog
  - Jobs_AuditLog
  - StockItems_AuditLog
  - StockTransactions_AuditLog

TRIGGERS
  - Insert/Update/Delete triggers on Users, Jobs, StockItems,
    StockTransactions that write to their respective audit tables.

STORED PROCEDURES (07_CREATE_STORED_PROCEDURES.sql)
  - usp_User_GetBySALNumber   (login lookup)
  - usp_User_GetById          (profile by UserID)
  - usp_User_UpdateLastLogin  (record login timestamp)

STORED PROCEDURES (08_STOCK_STORED_PROCEDURES.sql)
  - usp_Stock_GetById         (single stock item with job/location)
  - usp_Stock_Create          (insert stock item)
  - usp_Stock_Update          (update stock item)
  - usp_Stock_Delete          (delete stock item)

EXISTING DATABASE UPGRADE
  If ManageIT is already deployed, run only:
    08_STOCK_STORED_PROCEDURES.sql
  against the ManageIT database to add stock CRUD procedures.

SEED DATA
  - Demo users aligned with ERP frontend (SAL 10001/10002/10003)
  - Demo jobs, storage locations, and stock items

EXTRA TABLES (06_EXTRA_TABLES.sql)
  - InventoryAudits
  - Reconciliations

API BACKEND
  - See ../ManageIT.Api/ and project README.md
  - Run: dotnet run (serves frontend + REST API on http://localhost:5000)

================================================================
NOTES
================================================================
- Passwords are stored as password hashes (VARCHAR). The seed
  data uses a placeholder hash - replace with real bcrypt hashes
  generated by the backend.
- All tables use IDENTITY columns for primary keys.
- StockTransactions.QuantityBefore / QuantityAfter give a full
  audit trail for stock movements (matches the "History" screen
  in ManageIT).
